GOAL:

Improve the presentation of existing/verified images and image-capable areas across the public site without changing the site's restrained academic identity.

TASK 1 — INVENTORY EXISTING ASSETS

Quickly inspect the existing project assets and current image usage.

Identify:
- existing verified images
- existing logo/assets
- existing project/research images
- existing People/profile photos
- existing image components
- any existing media URLs/data already supported by the application

Do NOT perform a long historical audit.

Do NOT add new images simply to make pages look fuller.

TASK 2 — IMAGE PRESENTATION

Where verified existing images are already used, improve only their presentation:

Check:
- aspect ratio
- object-fit/object-position
- cropping
- image dimensions
- loading behavior
- consistent spacing
- captions/alt text where appropriate
- image-to-text relationship

Avoid:
- excessive rounded corners
- heavy shadows
- decorative frames
- oversized image blocks
- image carousels unless already part of the existing design

Keep imagery editorial and academic.

TASK 3 — PEOPLE / PROFILE IMAGES

Review existing People/profile image presentation.

If a verified photo exists:
- display it consistently
- preserve the person's identity/name relationship
- use accessible alt text
- avoid awkward cropping

If no verified photo exists:
- keep the existing text/neutral presentation
- do NOT substitute stock portraits
- do NOT use AI-generated portraits
- do NOT invent identities

TASK 4 — PROJECT / RESEARCH IMAGES

Review Projects, Research, and HumekaNeza for existing verified imagery.

If existing imagery is available:
- make presentation consistent
- preserve the current project text and links
- ensure images remain secondary to the research content

If imagery is not available:
- do not create placeholder photos
- do not add decorative stock imagery just to fill space

The site's academic content should remain complete without requiring images.

TASK 5 — RESPONSIVE IMAGE BEHAVIOR

Test image-capable pages at:

Desktop:
~1280px

Mobile:
~390px

Verify:
- no stretched images
- no distorted aspect ratios
- no image overflow
- no unexpected horizontal scrolling
- no text/image collisions
- image crops remain sensible
- image spacing remains consistent
- mobile images do not dominate the page

TASK 6 — PERFORMANCE / ACCESSIBILITY

For existing images where practical:
- preserve appropriate dimensions
- avoid unnecessary duplicate image loading
- use lazy loading for below-the-fold images where appropriate
- ensure meaningful alt text
- decorative images should not create unnecessary screen-reader noise

Do not introduce a new image optimization dependency unless absolutely necessary.

TASK 7 — RESPONSIVE PRESENTATION BEYOND IMAGES

While checking assets, fix only closely related presentation problems caused by:
- image dimensions
- media containers
- responsive grids
- image/text alignment
- mobile image spacing

Do NOT turn this into another general typography/layout pass.

TASK 8 — PRESERVE DESIGN SYSTEM

Maintain:
- off-white/neutral base
- charcoal typography
- muted teal accent
- restrained academic presentation
- ruled lists
- minimal visual decoration

Avoid:
- gradients
- glowing effects
- glassmorphism
- large rounded cards
- excessive shadows
- decorative graphics
- marketing-style image galleries

TASK 9 — FOOTER / HEADER

Do not redesign the header or footer.

Preserve:
- navigation
- mobile menu
- footer structure
- footer-logo behavior, including the existing triple-click behavior
