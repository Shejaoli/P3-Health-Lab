REFERENCE DESIGN DIRECTION:

The site should feel like a serious university research lab website:
- restrained
- academic
- editorial
- highly readable
- spacious but not oversized
- neutral/off-white base
- charcoal typography
- muted teal used sparingly
- ruled lists/dividers where appropriate

Avoid:
- gradients
- glowing effects
- excessive rounded cards
- heavy shadows
- glassmorphism
- decorative blobs
- excessive animations
- oversized marketing-style headings
- unnecessary UI redesigns

TASK 1 — TYPOGRAPHY

Review the existing global typography and make only targeted improvements.

Check:
- body font readability
- heading hierarchy
- page titles
- section headings
- eyebrow/label text
- navigation text
- body copy
- links
- metadata
- footer text

Ensure:
- heading sizes have a consistent hierarchy
- body text has comfortable line-height
- long academic paragraphs remain readable
- headings do not become unnecessarily huge
- links remain clearly identifiable without excessive visual treatment

Preserve any already-established typography that is working well.

TASK 2 — SPACING RHYTHM

Review the spacing between:
- header and hero
- hero title and description
- major sections
- section heading and content
- paragraphs
- ruled lists
- links
- footer sections

Create a consistent vertical rhythm across the public pages.

Avoid adding large empty spaces simply to make pages appear “premium”.

TASK 3 — LAYOUT WIDTH

Review the maximum content width and reading width.

Ensure:
- academic text is not stretched too wide
- list/table-like content remains readable
- important page content aligns consistently
- hero and body content feel like part of the same system

Do not force every section into identical widths if the existing design intentionally varies them.

Do not rewrite verified content.

TASK 5 — RESPONSIVE TYPOGRAPHY

Pay particular attention to mobile (~390px).

Verify:
- headings wrap naturally
- no awkward single-word lines where avoidable
- paragraphs remain readable
- navigation remains intact
- buttons/links do not overflow
- lists remain usable
- no horizontal scrolling

~1280px

~390px

Do NOT add animation as part of this phase.
